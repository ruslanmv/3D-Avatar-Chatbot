# VRMA Action Animations (Future Use)

[DavinciDreams/3dchat](https://github.com/DavinciDreams/3dchat).

**Status: NOT production-ready.** Same issues as vrma-dance — Mixamo bone names
cause inverted poses on VRM 0.x models.
