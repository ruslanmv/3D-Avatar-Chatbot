🔊 TTS Language Matrix

Verifies text-to-speech for every language in Settings, on both engines and both genders. Each cell shows the voice the app itself would choose (same selection logic as src/main.js and src/AppLanguage.js). Availability is detected automatically; gender and quality must be verified by ear — press ▶ (or Run all) and confirm each cell sounds like the right language and the right gender. Piper downloads each model (~20 MB) on first play.

Catalog facts are checked separately and automatically by node tests/piper-catalog-audit.mjs (voice IDs exist, speaker counts, language codes, who speaker 0 is). Run that first — this page is only for what a machine can't judge: how a voice sounds.
